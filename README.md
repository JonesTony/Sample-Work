# Data Processing Engine: Dictionaries, Lists, and Sets

A Python-based utility engineered to parse raw text data, manipulate structured data types, and automate file output generation.

## 🚀 Overview
This application processes raw input data from `.txt` source files to generate structured, formatted outputs saved dynamically into a designated `/OUTPUT` directory. The codebase demonstrates core software engineering practices by optimizing data lookups and filtering with structured Python collection types (dictionaries, lists, and sets).

## 🛠️ Tech Stack & Skills
* **Language:** Python 3
* **Scripting & Automation:** Bash / Shell scripting
* **Core Concepts:** File I/O operations, data structure optimization (hash maps/sets), automated output generation

## 📂 System Features
* **File Parsing:** Dynamically reads and extracts structured metrics from plain text files.
* **Optimized Storage:** Utilizes sets for fast uniqueness checks and dictionaries for mapping complex key-value data relations.
* **Output Management:** Automatically structures and dumps processing results into a local `/OUTPUT` directory for downstream use.
